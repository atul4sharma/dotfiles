# User Preferences

## Code style
- No comments unless the WHY is genuinely non-obvious (hidden constraint, workaround, surprising behavior).
- Keep responses terse — no trailing summaries of what was just done unless asked.

## Git
- Standard Claude Code defaults for commits and workflow (concise messages, ask before destructive actions).
- Never add `Co-Authored-By` or a Claude session link to commit messages.
- Commit messages and PR descriptions: bullet points, brief — never too detailed.
